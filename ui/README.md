# 基于 Web 的 Modbus 从站模拟器

简单、高效、可靠的 Modbus 从站设备模拟工具，支持多种协议和设备类型。

## 核心功能

- **多协议支持**：支持 Modbus TCP 和 Modbus RTU over TCP 协议
- **多设备管理**：在同一个 TCP 连接上模拟多个 Modbus 从站设备
- **全类型寄存器**：支持线圈、离散输入、输入寄存器和保持寄存器的初始值配置
- **实时事件订阅**：寄存器值变化时立即通知，实现实时监控
- **高性能**：基于 Go 语言开发的后端，性能优秀，资源占用低
- **简单配置**：通过 JSON 配置文件轻松设置设备，无需复杂的数据库配置

## 应用场景

1. **开发测试**：为 Modbus 主站开发人员提供模拟设备，方便测试和调试代码
2. **工业自动化**：在工业自动化系统中模拟各种 Modbus 设备，进行系统集成测试
3. **教育训练**：用于教学和培训，帮助学生理解 Modbus 通信原理和协议
4. **系统验证**：验证 Modbus 主站系统的兼容性和可靠性，确保系统稳定运行

## 快速入门指南

1. **创建设备**：在设备管理页面点击"新建设备"，填写设备基本信息
2. **配置参数**：选择协议类型，设置从站地址、IP 地址和端口等参数
3. **启动设备**：点击"启动服务"按钮，设备将开始监听 Modbus 请求
4. **监控和管理**：在控制台页面实时监控设备状态和修改寄存器值

## 设备配置示例

```json
{
  "deviceId": "device-1",
  "name": "测试设备",
  "protocol": "tcp",
  "slaveId": 1,
  "port": 502,
  "registers": {
    "coils": [0, 1, 0, 1],
    "discreteInputs": [1, 0, 1, 0],
    "inputRegisters": [123, 456, 789],
    "holdingRegisters": [987, 654, 321]
  }
}
```

## 界面功能说明

### 1. 首页

首页是应用的入口，提供了项目的整体介绍和核心功能展示：

- **项目介绍**：简洁明了地介绍了Modbus从站模拟器的核心价值
- **核心功能**：以卡片形式展示了6大核心功能，包括多协议支持、多设备管理、全类型寄存器等
- **快速入门**：通过四步流程，引导用户快速上手使用模拟器
- **应用场景**：展示了4种主要应用场景，包括开发测试、工业自动化、教育训练和系统验证
- **用户评价**：展示了来自不同领域用户的真实反馈
- **操作入口**：提供了快速进入设备管理页面的按钮

### 2. 设备详情页

设备详情页用于监控和管理特定Modbus设备的寄存器数据：

- **设备基本信息**：显示设备名称、SlaveID和协议类型
- **数据筛选**：支持按数据类型（线圈、离散输入、保持寄存器、输入寄存器）和显示格式（二进制、十进制、十六进制）筛选数据
- **地址范围设置**：允许用户设置要查看的数据点地址范围
- **数据点列表**：以卡片形式展示符合条件的数据点，包括地址和当前值
- **数据操作**：支持复制数据值和编辑数据点值
- **实时更新**：通过SSE（Server-Sent Events）实现寄存器值的实时更新
- **编辑模态框**：提供了直观的界面用于修改数据点值，支持不同数据类型的编辑

### 3. 关于页面

关于页面提供了项目的详细信息和联系方式：

- **产品介绍**：详细介绍了Modbus从站模拟器的定位和价值
- **技术优势**：列出了8个核心技术优势，包括高性能、双协议支持、多设备管理等
- **应用场景**：进一步说明了模拟器在不同领域的应用
- **联系信息**：提供了邮箱、电话和地址等联系方式
- **支持与反馈**：说明了获取支持的方式，包括邮箱和GitHub Issues
- **许可证信息**：展示了项目的MIT许可证信息
- **社交媒体链接**：提供了多种社交媒体平台的链接

### 4. 根布局

根布局是所有页面的基础框架，包含：

- **导航栏**：提供了网站的主要导航链接
- **页脚**：包含网站的版权信息和额外链接
